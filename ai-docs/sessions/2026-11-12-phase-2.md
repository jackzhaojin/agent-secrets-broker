## What I would tell the next agent

- **Check what a test does to things the owner set up by hand**, not just what it cleans up. The consent itself did the damage, before any cleanup ran.
- **Say when something wasn't tried in a browser.** Both browser bugs sat behind green scripted checks.
- **When a provider's console says no, read how the provider's own tools sign in.** That is where the working route was.
- **Record the negative before moving on.** B, the console finding and both of my mistakes are in the findings because they were written down when they happened.
- **Never run the sandbox end-to-end test during a live test window with Jack or Duet.**
